# Bundled fonts

Static TrueType files for embedding in PDFs. They are unmodified upstream files, distributed under the SIL Open Font License 1.1, which allows bundling as long as each family's license travels with it. Never edit, rename inside, or subset these files in place. To update one, replace it with a newer upstream file and update this table.
